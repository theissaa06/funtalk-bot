# FulTalchik Botik

## Запуск

```bash
npm install
npm start
```

## Railway Variables

- BOT_TOKEN
- BOT_USERNAME
- OWNER_ID
- NODE_ENV=production

Важно: не запускай локально и на Railway одновременно, иначе будет 409 Conflict.

## Новое

- команды со слешем и без слеша
- /калл все/админы/владельцы
- топ день/неделя/месяц/все
- действия в отношениях: обнять, поцеловать, шлепнуть, погладить и др.
- пятничный безопасный пост

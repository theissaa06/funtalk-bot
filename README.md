# 🤖 FunTalk AI Bot

Telegram-бот для общения, знакомств, мемов, прикольных приветствий и ИИ-помощника.

**Стек:** Node.js · Telegraf.js · JSON-хранилище · OpenAI / Claude / Gemini API

---

## 📦 Что умеет бот

| Раздел | Что делает |
|---|---|
| 💬 Общение | Темы для разговора, первые сообщения, ответы без кринжа |
| ❤️ Знакомства | Создание, просмотр, редактирование и удаление анкеты |
| 😂 Мемы | Случайные мемные фразы, реакции, ответы для переписки |
| 👋 Приветствия | 7 стилей: дружеское, мемное, милое, для знакомства и другие |
| 🎲 Случайная фраза | Вопросы для общения, мемные вопросы, фразы для знакомства |
| 🤖 ИИ-помощник | 5 режимов ИИ с памятью диалога (последние 10 сообщений) |
| ⚙️ Настройки | Стиль общения, режим ИИ |

## 🚀 Установка и запуск

### Требования

- **Node.js** версии 18 и выше: https://nodejs.org
- **VS Code**: https://code.visualstudio.com
- Аккаунт Telegram и бот от [@BotFather](https://t.me/BotFather)
- API-ключ одного из провайдеров ИИ (OpenAI, Claude или Gemini)

---

### Шаг 1 — Получить токен Telegram-бота

1. Открой Telegram, найди [@BotFather](https://t.me/BotFather)
2. Напиши `/newbot`
3. Введи название и юзернейм бота
4. Скопируй токен вида `1234567890:ABC-xxx...`

---

### Шаг 2 — Скачать проект

Если используешь Git:

```bash
git clone <ссылка-на-репозиторий>
cd funtalk-bot
```

Или просто открой папку проекта в VS Code.

---

### Шаг 3 — Установить зависимости

Открой терминал в VS Code (`Ctrl+`` ` или `View → Terminal`) и выполни:

```bash
npm install
```

---

### Шаг 4 — Создать файл .env

Скопируй шаблон:

```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# Mac / Linux
cp .env.example .env
```

Или просто создай файл `.env` в корне проекта и вставь:

```
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER

AI_PROVIDER=openai
OPENAI_API_KEY=ВАШ_КЛЮЧ_OPENAI
AI_MODEL=gpt-4o-mini

DATABASE_URL=./database.json
```

**Замени** `ВАШ_ТОКЕН_ОТ_BOTFATHER` и `ВАШ_КЛЮЧ_OPENAI` на реальные значения.

---

### Шаг 5 — Запустить бота

```bash
npm start
```

Или для режима разработки (автоперезапуск при изменениях):

```bash
npm run dev
```

Если в терминале появилось:

```
✅ FunTalk AI Bot запущен!
🤖 Провайдер ИИ: openai
```

— бот работает! Открывай Telegram и пиши ему `/start`.

## 🔑 Получение API-ключей ИИ

### OpenAI (рекомендуется для старта)

1. Зарегистрируйся на https://platform.openai.com
2. Перейди в раздел API Keys
3. Создай новый ключ
4. Укажи в `.env`:
   ```
   AI_PROVIDER=openai
   OPENAI_API_KEY=sk-...
   AI_MODEL=gpt-4o-mini
   ```

> 💡 `gpt-4o-mini` — дешёвый и быстрый вариант. Можно использовать `gpt-4o` для лучшего качества.

---

### Claude (Anthropic)

1. Зарегистрируйся на https://console.anthropic.com
2. Создай API-ключ
3. Укажи в `.env`:
   ```
   AI_PROVIDER=claude
   CLAUDE_API_KEY=sk-ant-...
   CLAUDE_MODEL=claude-3-5-sonnet-20241022
   ```

---

### Gemini (Google) — бесплатный тариф есть

1. Перейди на https://aistudio.google.com/app/apikey
2. Создай ключ
3. Укажи в `.env`:
   ```
   AI_PROVIDER=gemini
   GEMINI_API_KEY=...
   GEMINI_MODEL=gemini-1.5-flash
   ```

## 🛡 Безопасность

Бот **не помогает** со:

- взломом аккаунтов и устройств
- спамом и массовыми рассылками
- поиском личных данных других людей
- угрозами и оскорблениями
- травлей и харасментом

При подобных запросах бот отказывает и предлагает безопасную альтернативу.

## 🔧 Частые вопросы

**Бот не отвечает — что делать?**

1. Проверь, запущен ли процесс `npm start` в терминале
2. Убедись, что `BOT_TOKEN` в `.env` правильный
3. Напиши боту `/start`

**ИИ-помощник не работает**

1. Убедись, что `OPENAI_API_KEY` (или другой ключ) заполнен в `.env`
2. Проверь, что `AI_PROVIDER` соответствует заполненному ключу
3. Убедись, что на аккаунте ИИ-провайдера есть баланс

**База данных**

Файл `database.json` создаётся автоматически при первом запуске.  
Для сброса базы — удали файл `database.json` и перезапусти бота.
